# Ratgeber-Cluster — cover-image prompts (9 articles)

Filled from `image_prompt.md` §9 (base prompt + motif library + variation knobs). One prompt per article,
in publication order. Nothing here is new style direction — the motifs come from the §9 table and each one
matches the `coverAlt` already written in the article's frontmatter.

**Before you start (palette lock):** generate #1, then feed that image back as a colour reference on the other
eight ("match this colour grade, light and mood"). Alternatively use an existing cover
(`public/images/ratgeber-zeit.webp`) as the reference so the new nine match the three live ones.

**Negative prompt (paste on every one):**
`neon, electric blue, oversaturated, glowing, HDR, CGI, 3D render, cartoon, illustration, harsh contrast, people, text, letters, logo, watermark`

**After generating:** pick the calmest / most negative-space-heavy variant of 2–3, convert to **WebP quality 80**,
save under the exact filename given. `npm test` on this branch stays red until all nine exist.

### Watch-outs

- **#1, #5 and #9 are all flow motifs.** They sit at the top, middle and end of the run, and the knobs
  (dusk / straight-down / golden long-exposure) are what keeps them from reading as three takes of one shot.
  If two still look alike side by side, re-roll the middle one.
- **#7 is the brightest of the nine** (pale sandy bed). If the generated frame comes out light, the headline
  will not read over it — that is the one to check against a white title before accepting.
- **Filenames are load-bearing.** `ratgeber.corpus.test.ts` asserts the cover path matches the slug for all
  new articles, and `ratgeber.covers.test.ts` asserts the file physically exists.
