# Design-system primitives

Hero, backdrops, Reveal, utilities, focus/bare routes, copy modules and brand enforcement: the building blocks every page uses.
Token-based, reduced-motion-safe, CLS-safe, browser-verified 1440/390. Band orders, backdrops, tints per page → docs/pages.md.
- **Hero:** full-bleed water backdrop (`/images/hero-flow.webp`, `next/image fill priority` = LCP), centered text over a petrol `.hero-overlay-scrim`; slow zoom + 5 light motes, motion-safe; decorative `alt=""`; H1 reveal transform-only so LCP paints at once.
- **Centered spine (homepage):** heading + intro centered (`mx-auto max-w-[44rem] text-center`); blocks keep their form, **body text stays left-aligned**.
- **`Reveal`:** fade-up, one-way; hidden state gated behind `html.reveal-ready`, so **no-JS renders everything**.
- **Utilities:** `.card-depth`, `.shadow-deepwater`, `.cta-fx` (sheen + lift; filled `primary` + **`inverse`** = navy for warm/light surfaces where amber blends); `text-balance` headings, `text-pretty` body; eyebrow restraint.
- **Imagery:** prompts [image_prompt.md](image_prompt.md) → WebP in `public/images/`.
- **`SectionBackdrop`:** image `-z-20` + inline-rgba tint `-z-10` on an `isolate` section, tint per image so text clears AA. Homepage = one „rising from the deep“ ascent; subpages: dark band = image under petrol tint `27 80 99`, paper band = flat papier, every page closes on **`ClosingCta` = `bg-oberflaeche` (sonnenlicht 0.7)**, which always carries the seated founder portrait.
- **`CompactHero`** (`/leistungen` + subpages, `/faq`, `/ratgeber`, `/kontakt`): half a screen of image, eyebrow + H1 + one line (≤ 90 chars), no lead band, optional `cta`, left-to-right `tiefes-wasser` gradient (≥ 5.9:1). **`PageHero`** (Über-mich, parked pages): full-bleed image, title on the scrim, lead on paper as Fraunces standfirst with petrol drop-cap; `quality={65}`; optional `leadHeading` (only `/ueber-mich`) + `portrait`. **Newsletter keeps `PageIntro`**.
- **Forms** (Newsletter, Kontakt): **`WaterSection`** with **`bg-amber`** cards.
- **Focus routes (`ChromeGate`):** `focusRoutes` / `focusPrefixes` (`src/lib/nav.ts`) render **without site Header/Footer** (single-purpose pages: every nav link is an exit). `ChromeGate` (client, `usePathname()`) **swaps in** `FocusHeader`/`FocusFooter` (`src/components/focus/`), not `null`. **Pass `Header`/`Footer` as children, never as a prop** (RSC); `slot` says which half. CTA config in `focusChrome`; no `cta` = logo alone (`/prozess-check`: nothing exits before the result). ⚠️ **Focus chrome renders from the root layout, never the page**: a `<header>` inside `<main>` maps to **neither `banner` nor `contentinfo`**.
- **Bare routes (`bareRoutes`):** `ChromeGate` returns `null` for **both** slots (`/karte`, `/karte/qr`); root `<main>` stays the one landmark; the page carries `BrandLockup` + inline **Impressum/Datenschutz** links (Impressumspflicht).
- **Copy modules + guards:** one typed copy module per page (`src/lib/leistungenPages.ts`, `wartung.ts`, `kiAgenten.ts`, `garantie.ts`, `vorlagen.ts`, `referenzen.ts`, `regensburg.ts`, parked `makler.ts`, …); components hold no German strings. `src/lib/makler.test.ts` = the reusable **copy-guard** (walks the export, fails on ASCII quotes, **both dashes**, unbalanced „…“, a price token); `src/lib/ratgeberCopy.ts` + `ratgeber.corpus.test.ts` apply it to every Ratgeber body plus gendered forms and „, und“. Judgement rules (one water-metaphor *concept*, Merak landing, no CTA close) stay human.
- **Brand enforcement:** **`<BrandWord>`** (Fraunces italic for „Vrelo“/„Merak“) + the `@theme` tokens; never hand-roll colours or italics. `PageIntro`/`PageHero` auto-wrap brand words in `title`/`lead` (`withBrandWords`).
