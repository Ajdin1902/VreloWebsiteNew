**Goal:** Make vrelo-ki.de rank for the terms its buyers search (KI-/Prozessautomatisierung, Regensburg/Oberpfalz) with one small, code-only pass, plus a checklist of owner steps that need Ajdin's accounts.

## Review Focus

1. **A wrong `bauplan:` slug in an article** should fail the build loudly, the same way an unknown `leistung:` does, never render a dead link. → test in Task 4.
2. **A Leistungen page added later without `metaTitle`** should fail type-check, not silently fall back to a bare H1 title. → `metaTitle` is a required field (Task 3).
3. **The homepage title is the layout `default`**, so a subpage without its own `title` would show the homepage keyword title. → Task 3 test asserts the default and the template separately.
4. **The local page must not be orphaned:** a page linked from nothing gets no crawl. → Task 5 tests the sitemap entry and the footer link.
5. **Static sitemap entries with a faked date** teach Google to ignore `lastmod`. → Task 1 asserts static entries carry none and articles carry their own date.
