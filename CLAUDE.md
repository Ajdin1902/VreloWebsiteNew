## What this is
A content/SEO marketing site for Vrelo, an AI-automation studio for „Betriebe und Unternehmen“ in DACH (descriptor since 2026-10-01, Brand.md §5). Framed as a **personal brand** (first-person „Ich“). Primary goal: convert visitors to a booked call (scheduler) or contact form; secondary: organic search via a German Ratgeber (blog) + a newsletter.

## Design system (durable patterns)
All `@theme`-token-based, reduced-motion-safe, CLS-safe, browser-verified 1440/390. Reusable warnings under *Gotchas*.
- **Hero:** full-bleed flowing-water backdrop (`/images/hero-flow.webp`, `next/image fill priority` = LCP) with centered overlay text over a petrol `.hero-overlay-scrim`; slow ambient zoom + 5 drifting light motes, motion-safe-gated; decorative `alt=""`; H1 reveal is transform-only so LCP paints immediately.
- **Centered spine (homepage):** each section centers heading + intro (`mx-auto max-w-[44rem] text-center`); content blocks keep their stronger form and **body text stays left-aligned** (centered body hurts scanning).
- **Scroll-motion:** shared **`Reveal`** primitive (fade-up, one-way; hidden state gated behind `html.reveal-ready` so **no-JS renders everything visible**).
- **Depth/craft utilities:** `.card-depth`, `.shadow-deepwater`, `.cta-fx` (CTA sheen+lift; filled variants `primary` + **`inverse`** = navy fill for warm/light surfaces where amber blends); `text-balance` on headings, `text-pretty` on body; eyebrow restraint.
- **Imagery:** shared **`PageImage`**; `PageIntro`'s optional `image` prop drives page banners; cohesive water photography below the fold (Hero stays LCP, German alt). Prompts in [image_prompt.md](image_prompt.md) → optimized WebP in `public/images/`.
- **Homepage order + Spine A backdrops:** Hero → Problem → **Der Weg** (`DerWeg`: Vorlage holen → Gespräch → Fahrplan, all free, own CTA `?src=home-weg`; right after the pain because it explains the hero button) → Was ich baue (the three doors as cards since 2026-11-11, Prüfen → audit page, Bauen → `/leistungen#gruppe-bauen`, Betreiben → Betreuung page) → **Werkzeuge** → Proof (six value cards incl. guarantee + ownership) → Referenzen → Merak, one continuous **"rising from the deep"** ascent — luminance/temperature/depth all point the same way as you scroll. The deep sections climb, then the surface breaks once at Proof and holds warm through Merak (no dip). Each section carries a full-bleed water backdrop via the reusable **`SectionBackdrop`** primitive (image `-z-20` + inline-rgba tint `-z-10` on an `isolate` section; tints per-image so light/dark text clears AA — all values measured). Deep stretch = `tone="cool"` (tiefes-wasser), **light text on faint `bg-gletscher/10` glass tiles**: Problem navy-dusk 0.6 · Was-ich-baue dark karst pool (ripples) 0.5 · Werkzeuge karst spring 0.75. **Surface break = Proof** flips to `tone="warm"` — a Fließen river (sonnenlicht 0.55) with **frosted `bg-papier/70` glass cards** and a deep-espresso `#33210f` heading on a soft sunlit glow, handing off warm-to-warm into the warm `MerakClose` sunset. Card vocabulary is shared: glass tiles on the deep sections, frosted papier on the light one. Small warm accents thread the page (amber CTAs/badges, Problem amber dots, a small amber rule in Werkzeuge); **amber-the-token is too dark for small text on the deep base (3.65:1) — use `honig` for warm text on dark.** **`Werkzeuge`** = „Läuft mit deinen Werkzeugen“ — trademark-safe tool-*name* grid (no logos, no carousel; `min-h-[2lh]` on cluster labels keeps card rows aligned when a label wraps).

## Gotchas
- **German quotes** „…“ = U+201E (open) + U+201C (close) — never ASCII `"`. Edit/Write silently downgrade the closing quote (and turn `\xNN` code-escapes typed into content into literal control bytes). Verify bytes after writing, then repair with **codepoint escapes** (literal smart chars in the `-e` program don't survive): `perl -CSD -i -pe 's/\x{201E}([^\x{201E}"]*)"/\x{201E}$1\x{201C}/g' FILE`. ⚠ That first pattern is greedy across a line: it will also eat a legitimate ASCII `"` further along the same line. Repair line-ranges, then re-audit. Write fix scripts as **files** using `chr(0x…)`: inline `python -c` and heredocs lose an escape level (a `\b` landed in a test as a 0x08 byte, 2026-10-04).
- **German dash (founder decision 2026-08-16):** **no Gedankenstrich in German copy.** Neither the spaced en-dash (U+2013) nor the em-dash (U+2014) belongs in client copy; join clauses with a comma, a period, or a colon, and write number ranges with the word bis (e.g. `1 bis 2`). The copy-guard tests forbid both dashes; English code comments may keep the em-dash.
- **No comma before „und“ (Ajdin 2026-10-01: „Humans do not do that.“):** drop it between main clauses and list items; where grammar needs it (it closes a subordinate or relative clause, an insertion, or precedes „und zwar“), rephrase, usually by splitting the sentence. Enforced by `findCopyIssues` (Ratgeber + Leistungen data) and `src/lib/kommaUnd.test.ts` (all of `src/`).
- **Quote constants must be codepoint escapes, never literal characters.** `ratgeberCopy.ts` writes `"\u201C"` / `"\u201D"` deliberately: Write/Edit downgrade a literal U+201C to U+201D, which would silently make `CLOSE_QUOTE === WRONG_CLOSE` and leave a detector that can never fire. Same reason its bad-quote *test fixture* is an escape — a typography repair pass over the test file would otherwise „fix“ the fixture and the test would assert against clean input. (This bit twice in one session.)
- **Der Korpus-Test prüft jede Datei einzeln — Serien-Masche sieht er nicht.** Beim 9-Artikel-Batch schlossen 7 von 12 Artikeln auf demselben Satzstamm („Das ist der Merak-Effekt“) und 7 von 9 Pull-Quotes auf derselben Figur („X ist nicht Y. Es ist Z.“) — jeder Artikel für sich gut, hintereinander gelesen eine Masche. Nach jedem Batch die Schlusssätze und Pull-Quotes **als Liste** lesen (`grep -h '^> ' content/ratgeber/*.mdx`), nicht Datei für Datei.
- **CRLF vs. the Edit tool:** several existing test files (e.g. `src/components/kontakt/SchedulerEmbed.test.tsx`) are stored CRLF. The Edit tool matches on LF and fails to find the string. Append via a small script doing a CRLF-aware replace, then verify the file is intact.

- **Never wrap an anchored element in `Reveal`:** its hidden state is translated, so a hash or 308 jump lands the target under the sticky header (KI cards on KI-Automatisierung; `blocks.test.tsx` pins that no anchor sits inside `[data-shown]`).

- **`backdrop-filter` containing block:** any element with `backdrop-filter`/`backdrop-blur` becomes the containing block for `fixed` descendants — portal full-screen overlays out to `document.body` (see `MobileNav`).
- **Section backdrop = `isolate`:** a `-z-…` decorative image inside a `Section` paints *behind the section's own opaque background* unless the section is a stacking context. `position: relative` alone is **not** one. Add **`isolate`** (see `Proof`/`MerakClose`).

## How we work
Greenfield workflow via the superpowers skills, one feature/phase at a time, each on its own `feat/*` (or `fix/*`) branch:
1. **brainstorm** → design decisions (visual choices resolved via live demos)
2. **writing-plans** → bite-sized, TDD, per-task-commit plan in `docs/superpowers/plans/`
3. **build** → verified on test/tsc/lint/build, then code review
4. **finishing-a-development-branch** → merge to `main`

Frequent commits; commit messages end with a `Co-Authored-By:` line naming the model that actually wrote them. ⚠️ PowerShell 5.1 splits `git commit -m` at embedded quotes (stray pathspec errors, nothing committed): write the message to a file and `git commit -F`. **Publishing content while the checkout sits on an unmerged `feat/*`:** `git worktree add <tmp> main`, copy only the new files, commit + push there, `git worktree remove`; then delete the local untracked copies once `git hash-object <f>` equals `git rev-parse main:<f>`, or they block the next `git checkout main`.
