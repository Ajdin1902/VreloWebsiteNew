## Design system (primitives)
Token-based, reduced-motion-safe, CLS-safe, browser-verified 1440/390. Band orders, backdrops, tints per page → docs/pages.md.
- **Hero:** full-bleed water backdrop (`/images/hero-flow.webp`, `next/image fill priority` = LCP), centered text over a petrol `.hero-overlay-scrim`; slow zoom + 5 light motes, motion-safe; decorative `alt=""`; H1 reveal transform-only so LCP paints at once. (Calm „system runs itself“ flow, chosen over a warm *Merak* desk scene.)
- **Centered spine (homepage):** heading + intro centered (`mx-auto max-w-[44rem] text-center`); blocks keep their form, **body text stays left-aligned**.
- **`Reveal`:** fade-up, one-way; hidden state gated behind `html.reveal-ready`, so **no-JS renders everything**.
- **Utilities:** `.card-depth`, `.shadow-deepwater`, `.cta-fx` (sheen + lift; filled `primary` + **`inverse`** = navy for warm/light surfaces where amber blends); `text-balance` headings, `text-pretty` body; eyebrow restraint.
- **Imagery:** `PageImage`; `PageIntro`'s `image` prop drives banners; water photography below the fold (German alt). Prompts [image_prompt.md](image_prompt.md) → WebP in `public/images/`.
- **`SectionBackdrop`:** image `-z-20` + inline-rgba tint `-z-10` on an `isolate` section, tint per image so text clears AA (measured 1440 + 390). Homepage = one „rising from the deep“ ascent; subpages: dark band = image under petrol tint `27 80 99`, paper band = flat papier, every page closes on **`ClosingCta` = `bg-oberflaeche` (sonnenlicht 0.7)**, which always carries the seated founder portrait.
- **`CompactHero`** (`/leistungen` + subpages, `/faq`, `/ratgeber`, `/kontakt`): half a screen of image, eyebrow + H1 + one line (≤ 90 chars), no lead band, optional `cta`, left-to-right `tiefes-wasser` gradient (≥ 5.9:1). **`PageHero`** (Über-mich, parked pages): full-bleed image, title on the scrim, lead on paper as Fraunces standfirst with petrol drop-cap; `quality={65}`; optional `leadHeading` (only `/ueber-mich`) + `portrait`. **Newsletter keeps `PageIntro`** (a cool hero on the cool form read as water-on-water).
- **Subpage rhythm:** Über-mich / FAQ alternate petrol and papier via `index % 2 === 1`, `onDark` variants (`StoryBeat`, `FaqItem`). Newsletter + Kontakt forms: **`WaterSection`** (`src` prop) with **`bg-amber`** cards.
- **Focus routes (`ChromeGate`):** `focusRoutes` / `focusPrefixes` (`src/lib/nav.ts`) render **without site Header/Footer** (single-purpose pages: every nav link is an exit). `ChromeGate` (client, `usePathname()`) **swaps in** `FocusHeader`/`FocusFooter` (`src/components/focus/`), not `null`. **Pass `Header`/`Footer` as children, never as a prop** (RSC); `slot` says which half. CTA config in `focusChrome`; no `cta` = logo alone (`/prozess-check`: nothing exits before the result; parked `/makler` + `/lead-check` were focus routes, `/demo` kept full chrome). ⚠️ **Focus chrome renders from the root layout, never the page**: a `<header>` inside `<main>` maps to **neither `banner` nor `contentinfo`** (`/makler` once had one landmark, zero `<nav>`).
- **Bare routes (`bareRoutes`):** `ChromeGate` returns `null` for **both** slots (`/karte`, `/karte/qr`); root `<main>` stays the one landmark; the page carries `BrandLockup` + inline **Impressum/Datenschutz** links (Impressumspflicht).
- **Copy modules + guards:** one typed copy module per page (`src/lib/leistungenPages.ts`, `wartung.ts`, `kiAgenten.ts`, `garantie.ts`, `vorlagen.ts`, `referenzen.ts`, `regensburg.ts`, parked `makler.ts`, …); components hold no German strings. `src/lib/makler.test.ts` = the reusable **copy-guard** (walks the export, fails on ASCII quotes, **both dashes**, unbalanced „…“, a price token); `src/lib/ratgeberCopy.ts` + `ratgeber.corpus.test.ts` apply it to every Ratgeber body plus gendered forms and „, und“. Judgement rules (one water-metaphor *concept*, Merak landing, no CTA close) stay human.
- **Brand enforcement:** **`<BrandWord>`** (Fraunces italic for „Vrelo“/„Merak“) + the `@theme` tokens; never hand-roll colours or italics. `PageIntro`/`PageHero` auto-wrap brand words in `title`/`lead` (`withBrandWords`).

## Gotchas
- **Typography bytes:** Edit/Write silently downgrade the closing quote U+201C (and turn `\xNN` typed into content into control bytes). Verify bytes after writing; repair with **codepoint escapes** (literal smart chars in `-e` don't survive): `perl -CSD -i -pe 's/\x{201E}([^\x{201E}"]*)"/\x{201E}$1\x{201C}/g' FILE`. ⚠ Greedy across a line, eats a legit ASCII `"` further on: repair line ranges, re-audit. Fix scripts as **files** with `chr(0x…)`: `python -c` and heredocs lose an escape level (a `\b` once became a 0x08 byte).
- **Copy guards:** both dashes (U+2013, U+2014) fail the copy-guard tests (English comments may keep the em-dash); „, und“ fails `findCopyIssues` (Ratgeber + Leistungen data) and `src/lib/kommaUnd.test.ts` (all of `src/`); where grammar needs the comma, rephrase.
- **Quote constants = codepoint escapes, never literals:** `ratgeberCopy.ts` writes `"\u201C"` / `"\u201D"` so a downgrade can't make `CLOSE_QUOTE === WRONG_CLOSE` (a detector that never fires); its bad-quote test fixture is an escape too (a repair pass would „fix“ it).
- **The corpus test sees files, not series:** 7 of 12 articles once closed on „Das ist der Merak-Effekt“, 7 of 9 pull quotes on „X ist nicht Y. Es ist Z.“. After a batch read closings + pull quotes **as a list** (`grep -h '^> ' content/ratgeber/*.mdx`).
- **CRLF files** (e.g. `src/components/kontakt/SchedulerEmbed.test.tsx`): Edit matches LF and fails; use a CRLF-aware replace script, verify.
- **Anchors:** `scroll-mt-*` must sit on the element with the `id` (see `TerminSection`), not an ancestor. **Never wrap an anchored element in `Reveal`** (translated hidden state → a hash/308 jump lands under the sticky header; `blocks.test.tsx` pins it).
- **Tokens (AA overrides, confirm with the founder before reverting):** `papier #f4efe6` base; **Ratgeber articles only** `lesepapier #ece3d2` via `Section tone="reading"` (stumm 4.67, ember 5.13, tinte 14.0; sepia `#e7ddc9` would drop stumm below 4.5), body `text-lg`. `stumm #696359` (Brand.md `#7a7468`, 5.19:1 on papier) + `ember #7e5527` (Brand.md `#8b5e2c`, small text on sonnenlicht) darkened. Dark sections: body grey `gletscher #dce7eb` (7:1 petrol, 12:1 deep water); `stein #a8b5ba` only on `tiefes-wasser #0a2538` (Footer 7.5:1), **never `text-stein` on `vrelo-petrol`** (4.2:1). Hero text on the photo needs `.hero-overlay-scrim`. **`amber` fails small text on the deep base (3.65:1): warm text on dark = `honig`.**
- **`bg-amber #d4a24c` form cards:** links navy (`lightLinkClass`; `text-vrelo-petrol` = 3.8:1), errors `signal-tief #6b1f14` (4.95:1), text navy/`tinte`, `bg-papier` inputs, navy button. On dark: `signal #f0a79a` + `darkLinkClass`. Footer `NewsletterForm` keeps amber button + `ember` error.
- **Cal.com:** account `ajdin-dzafic-vrelo/30min` is on **`cal.com`** (`SchedulerEmbed` pins `calOrigin="https://cal.com"`, `calBookingUrl()` → `https://cal.com/${slug}`); ⚠️ **`cal.eu` 404s it**. Slug only in Vercel env `NEXT_PUBLIC_CAL_LINK` (Production + Development; Preview unset). Iframe loads on click only. Detail → docs/pages.md.
- **OG images:** satori needs a **static** TTF: `src/app/_og/Fraunces-SemiBold-static.ttf`.
- **Share meta: never set `openGraph`/`twitter` title or description per page** (a page `openGraph` replaces the layout's whole object, losing og:locale/siteName and the `— Vrelo` template; an absolute `twitter.title` in the layout once showed homepage text everywhere). Set `title` + `description` only; the root `opengraph-image` applies everywhere. (`/ratgeber/[slug]` keeps `openGraph.type: "article"`.)
- **FAQ deep links:** answers carry `id={faqAnchor(question)}` (`src/lib/faq.ts`); link via `faqHref("<exact question>")`, `OpenFaqFromHash` opens it; test the anchor exists (`Proof.test.tsx`, `faq.test.ts`).
- **Tests:** `getByText` sees only own text nodes (a sentence split by `<strong>` never matches): `getByText((_, el) => el?.tagName === "LI" && el.textContent === text)`. Vitest v4: `vi.mock("resend")` needs a constructable `function`/`class`; a top-level `vi.fn()` used in a `vi.mock` factory throws `Cannot access … before initialization` → **`vi.hoisted(() => ({ … }))`**.
- **Resend:** Segments (ex-Audiences); signup = `contacts.create({ segments:[{ id }] })` (`NEWSLETTER_SEGMENT_ID`). **`RESEND_API_KEY` needs Full access** (sending-only 401s `restricted_api_key`). `confirmSubscription` logs Resend errors to Vercel runtime logs.
- **RSC:** never pass a component **as a prop** (`as={Link}`) Server → Client; pass a child. Client components can't import runtime values from `@/lib/ratgeber` (`fs`): `KategorieFilter` gets server-rendered `ArticleCard` nodes; `import type` is fine.
- **`backdrop-filter`/`backdrop-blur`** = containing block for `fixed` children: portal overlays to `document.body` (`MobileNav`).
- **Section backdrop needs `isolate`:** a `-z-…` image paints behind the section's own background unless it's a stacking context (`relative` isn't); see `Proof`/`MerakClose`.
- **Stacked `Section`s double padding** (`PageIntro`/`PageHero` end in `py-24 md:py-32`): pull up with `-mt-24 md:-mt-32` **only the first section after the hero**; later bands keep full symmetric `py`, the tone contrast is the divider (on an alternating ribbon `-mt` makes cards butt the seam). **Never after `CompactHero`** (ends on a dark band). Separate by `tone`/`tint`, not lines. **Footer has no top margin; never add `mt-*`.**
- **Local servers:** manual/Playwright checks on `npm start`; scroll full-page screenshots through first (`Reveal`). A stopped background `next start`/`next dev` leaves a Node child on :3000 serving the old build: kill the port holder (`Get-NetTCPConnection -LocalPort 3000`). ⚠️ **Run servers and Vitest from `C:\…`, never `c:\…`, `c:/` or `/c/…`**, e.g. `cd "C:/Users/ajdin/Vrelo/Website"` (else `next dev` 404s every route and Vitest fails `Cannot read properties of undefined (reading 'config')`). Drafts render only under `next dev`. Stop all servers before `npm run build` (else `next/font/google queries have exactly one entry`). Turbopack panic on `globals.css` (PostCSS „timeout while receiving message“) = load: rerun.
- **Images:** WebP derivatives committed in `public/images/` (`sharp`, quality 80); source `Images/` gitignored **root-anchored `/Images/`** (unanchored it matches `public/images/` on case-insensitive Windows Git). Next 16 `images.qualities` is an allow-list (`[65, 75]`, else HTTP 400); `deviceSizes` capped at 1920 so `sizes="100vw"` never offers 3840. A sometimes-slow hero = Vercel optimizer cold cache (first image+width MISS ~0.7–0.9 s, then HIT ~0.16 s, resets per deploy).
- **`LazyVideo`:** the video primitive (poster `<img>` for reduced motion via `useSyncExternalStore`, IntersectionObserver play/pause, `preload="none"`). Re-cut a clip → `npm run optimize:videos`, commit source + `public/video/` derivatives together; mapping → docs/pages.md.
