Der Begriff KI-Agent steht gerade auf jeder zweiten Produktseite. Mal ist ein Chatbot gemeint, mal eine einfache Automatisierung, mal etwas ganz anderes. Für deine Entscheidung reicht ein klares Bild von drei Dingen.

## Drei Dinge, die oft verwechselt werden

- **Ein Chatbot** beantwortet Fragen. Er sagt dir etwas, er erledigt nichts.
- **Eine Automatisierung** folgt festen Regeln: Kommt eine Rechnung, legt sie diese im richtigen Ordner ab. Sie handelt, aber nur so, wie ich es vorher festgelegt habe.
- **Ein KI-Agent** bekommt ein Ziel und Werkzeuge. Er liest eine Nachricht, entscheidet, welcher Schritt passt, und führt ihn aus: einen Termin eintragen, eine Aufgabe anlegen, eine Rechnung vorbereiten.

Der Unterschied liegt im Entscheiden. Eine Automatisierung braucht Eingaben in fester Form. Ein Agent versteht auch eine Sprachnachricht wie „Morgen um neun bei Firma Berger, Heizung tauschen, danach Rechnung schicken“ und macht daraus drei Einträge.

## Wo ein Agent im Betrieb hilft

Überall dort, wo Arbeit in freier Form hereinkommt, aber in feste Abläufe soll. Ein Beispiel aus meiner Arbeit: Ein Hausmeisterservice gibt seinem Assistenten unterwegs per Sprachnachricht Aufgaben. Der Assistent legt Termine an, notiert Aufträge und bereitet Rechnungen vor. Der Inhaber tippt abends nichts mehr nach.

Weitere typische Fälle:

- E-Mails lesen und vorsortieren: Anfrage, Rechnung, Reklamation, Werbung.
- Unterlagen prüfen und bei Lücken eine freundliche Nachfrage als Entwurf schreiben.
- Fragen zu euren eigenen Dokumenten beantworten, mit Verweis auf die Fundstelle.

> „Ein Agent darf vorbereiten, so viel er will. Was Folgen hat, bestätigt ein Mensch.“

## Welche Grenzen ein Agent braucht

Ein Agent entscheidet, und Entscheidungen können falsch sein. Deshalb baue ich drei Grenzen ein:

1. **Entwurf statt Versand.** Alles, was nach außen geht oder Geld bewegt, legt der Agent als Entwurf an. Du gibst es frei.
2. **Nur die nötigen Werkzeuge.** Ein Agent, der Termine eintragen soll, bekommt keinen Zugriff auf die Buchhaltung.
3. **Ein Protokoll.** Der Agent schreibt jeden Schritt mit, damit du nachvollziehen kannst, was er getan hat und warum.

Schreibt ein Agent mit deinen Kunden, sagt er von sich aus, dass er eine KI ist. Das ist seit August 2026 Pflicht, und Kunden wissen es ohnehin gern.

## Brauchst du überhaupt einen?

Oft nicht. Kommt eine Aufgabe immer in derselben Form, reicht eine einfache Automatisierung. Sie kostet weniger und tut jedes Mal exakt dasselbe. Ein Agent lohnt sich dort, wo die Eingaben unterschiedlich aussehen: Sprachnachrichten, freie E-Mails, gemischte Unterlagen.

Frag dich deshalb zuerst, welche Arbeit bei dir in freier Form ankommt. Nimmt dir ein Agent genau diese ab, endet dein Tag ohne Nacharbeit am Abend. Dieses ruhige Gefühl nenne ich den Merak-Effekt.
